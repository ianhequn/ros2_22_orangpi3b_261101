# 验证教程（真机）

按 0→3 级顺序做，**每级通过再进下一级**，出问题能立刻定位是串口/协议、ros2_control、还是控制方向。

所有可变参数都在 `config/dd_chassis_001.ros2_control.xacro` 里，先填这三项：
`serial_device`（如 `/dev/ttyS1`）、`baud_rate`、`frame_end`（固件帧尾真值，支持 `0x` 写法）。

环境准备：
```bash
sudo apt install ros-humble-xacro python3-serial ros-humble-ros2-control ros-humble-ros2-controllers
cd ~/MyWork/Robot/ros2/ws_orangepi_01 && colcon build --symlink-install && source install/setup.bash
```
串口权限：把用户加进 `dialout` 组（`sudo usermod -aG dialout $USER`，重新登录生效）。

## 第 0 级：裸串口自检（不依赖 ros2_control）

```bash
ros2 run DD_Chassis_001_driver serial_monitor.py --device /dev/ttyS1 --frame-end 0x55AA55AA
```

期望：每 0.5s 打出一行，**帧率≈120Hz**，`speed0/speed1` 随手动转轮子变化，`imu1~3` 随车身姿态变化。

| 现象 | 原因 |
| --- | --- |
| 一直 `收不到有效帧` | `frame_end` 值不对 / 波特率不匹配 / 设备选错 |
| 帧率明显低于 120Hz 且跳变 | 波特率偏低（120Hz×64B≈62kbps，至少 115200） |
| `speed` 有值但正负与转向相反 | 记下来，后面用 `left/right_invert` 修正 |

固件速度单位和真实 rad/s 不一样，所以在确认能收到帧后立刻**标定**（可跳过，`speed_scale` 先用 1.0）：

```bash
# 让固件把电机 0 设到目标值 10，采样 2s，统计上报 speed 的平均值
ros2 run DD_Chassis_001_driver serial_monitor.py --calibrate-motor 0 --target 10 --measured-rad-s 12.5
```
`measured-rad-s` 的测法：手动让轮子转 N 圈，计时 t 秒，则 rad/s = 2πN/t（让固件以目标值稳定运行后测）。
脚本会打印 `建议 speed_scale = measured_rad_s / speed_avg`，填进 xacro 的 `left_speed_scale`，电机 1 同理填 `right_speed_scale`。

## 第 1 级：插件与控制器能起来

```bash
ros2 launch DD_Chassis_001_driver chassis_test.launch.py
```

期望日志（顺序）：
```
底盘串口已打开: /dev/ttyS1 @ 115200, frame_end=0x...
IMU 发布已启动: topic=imu frame=imu_link rate=100Hz
Loading hardware from: /controller_manager robot_description
Successful 'joint_state_broadcaster' ... 'diff_drive_controller'
```

再开一个终端确认硬件接口已注册：
```bash
ros2 control list_hardware_interfaces
# 应看到 wheel_l/wheel_r 的 velocity(command)、position/velocity(state)，且 command 被控制器占用
ros2 control list_hardware_components   # 状态 ACTIVE
```

| 现象 | 原因 |
| --- | --- |
| `必须配置 frame_end` | xacro 里还没填 |
| `打开串口失败 ... Permission denied` | 没加 dialout 组 |
| `URDF 里找不到关节 "wheel_l"` | xacro 的 joint 名与 `left/right_wheel_joint` 不一致 |
| spawner 报 controller 不存在 | controllers.yaml 路径或 `controller_manager` 参数没传进去 |

## 第 2 级：数据流出对不对

`chassis_test.launch.py` 默认会启动 `chassis_monitor.py` 打表（不想看就加 `serial_debug:=false`）：
```
关节速度[rad/s] wheel_l= +0.000 wheel_r= +0.000 | yaw= +0.00° yaw_rate= +0.000 | odom vx= +0.000 wz= +0.000
```

逐项验证：

1. **轮速**：手转左轮，`wheel_l` 变化、`wheel_r` 不动。
2. **方向（关键）**：驱动轮朝前推 → 两轮 `velocity` 都应为正。
3. **IMU yaw**：车体逆时针（俯视）转 → `yaw` 增大（0→+90°）。
   - `yaw` 相反：改 `imu_yaw_sign: -1`。
   - `yaw` 不随车体转：`imu_yaw_field` 选错，换 1/2/3 试。
   - 角度单位不对（转 90° 显示 1.57）：`imu_angle_is_deg` 应为 `true`。
4. **频率**：
```bash
ros2 topic hz /imu                     # ≈ imu_publish_rate(100)
ros2 topic hz /joint_states            # ≈ 控制器 update_rate(100)
ros2 topic echo /imu --once            # orientation.z/w 非 0，angular_velocity_covariance[8]=0.01
```
5. **通信中断保护**：拔掉底盘串口，日志应出现 `超过 500 ms 未收到有效数据帧`，`wheel_l/r` 归零。

## 第 3 级：指令闭环

```bash
# 直行 0.05 m/s（5cm/s，慢速安全）
ros2 topic pub -r 10 /diff_drive_controller/cmd_vel_unstamped \
  geometry_msgs/msg/Twist '{linear: {x: 0.05}}'

# 原地左转（逆时针，z>0）
ros2 topic pub -r 10 /diff_drive_controller/cmd_vel_unstamped \
  geometry_msgs/msg/Twist '{angular: {z: 0.3}}'
```

也可以用打表工具直接发，省一个终端：
```bash
ros2 run DD_Chassis_001_driver chassis_monitor.py --cmd-vx 0.05     # 持续直行
ros2 run DD_Chassis_001_driver chassis_monitor.py --cmd-wz 0.3      # 持续左转
```

检查表：

| 项目 | 期望 |
| --- | --- |
| 直行 | 两轮同向、车走直线；`odom vx ≈ 0.05` |
| 左转 | 左轮反转、右轮正转，车逆时针 |
| 停车 | 停发 cmd_vel 超过 `cmd_vel_timeout`(0.5s) → 两轮自动归零 |
| 里程计 | 车直线走 1m，`odom` 的 x 变化 ≈1m（差得多就回去修 `speed_scale` / `wheel_radius`） |

方向不对的修法（只改 xacro，不改代码）：
- 某轮整体方向反了（发前进指令该轮反转）→ 该轮 `left_invert/right_invert: true`
- 两轮都反 → 同上两个都改
- yaw 方向反 → `imu_yaw_sign: -1`

限速：`max_wheel_velocity`（rad/s）是硬限幅，实际线速度 ≈ 该值 × `wheel_radius`。首次上电建议先设小（如 5.0）。

## 常见问题速查

| 现象 | 排查方向 |
| --- | --- |
| 串口能开但一直没帧 | `frame_end` 真值；用 `serial_monitor.py` 直接 hexdump 原始字节确认 |
| 帧解析偶尔跳 | 串口上有其它设备/回显，或波特率不够导致丢字节 |
| 控制器加载了但轮子不动 | `ros2 control list_controllers` 是否 active；cmd 话题名是否是 `.../cmd_vel_unstamped` |
| 车在跑但 odom 不动 | `position_feedback`/硬件组件 read 没拿到帧（看日志 timeout 警告） |
| /imu 没数据 | `publish_imu` 是否 true；`ros2 node list` 有没有 `dd_chassis_001_imu` |
